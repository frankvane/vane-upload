## L2 共享层 / 消息协议

`★ L2-1 [Critical]【确认】相对 baseURL 让鉴权头全部漏发`
- 证据：`normalizeHost` 对无法解析的输入补 `https://` 再取 host（`urlSafety.ts:19-30`）；`getAllowedHosts({baseURL:"/api"})` → `new URL("https:///api").host === "api"` → `["api"]`；`isUrlAllowed("/api/file/check", ["api"])` 中 `new URL(相对URL)` 抛错 → `return false`；`fetchWithRetry.ts:66` 的 `sendAuth = isUrlAllowed(url, allowedHosts)` 为 false 时不合并 `authHeaders`。而 `src/shared/url.test.ts:50-53` **明确支持相对 base**（`joinUrl("/api","/file/merge") === "/api/file/merge"`）。
- 影响：宿主用 `baseURL="/api"`（很常见的同源部署写法）时，`/check`、`/status`、`/upload`、`/merge` 全部不带 `Authorization`/自定义鉴权头 → 401，上传必失败。`baseURL=""` 时白名单为 `[]`，`isUrlAllowed` 恒 true（设计上的「向后兼容」）；由于此时 URL 都是同源相对路径，实际外泄风险有限，但防护语义为零。
- 判据：新增 `getAllowedHosts({baseURL:"/api"})` 与 `isUrlAllowed(joinUrl("/api","/file/x"), ...)` 断言应返回 true（当前必红）；浏览器用相对 base + authHeaders 实跑得 401。
- 修复：`normalizeHost` 对以 `/` 开头的相对路径返回 `null`；`isUrlAllowed` 用 `self.location.origin` 作 base 解析相对 URL；空白名单改为「仅同域允许」而非无条件 true。

`○ L7-9 [Optional]【疑似】chunkStateQueue 的 flush 失败恢复无条件覆盖期间新入队状态`

`○ L7-10 [Optional]【确认】fileSecurity 未做 Unicode 归一化/混淆字符过滤`
- `utils/fileSecurity.js:11-15` 只过滤 ASCII 危险字符与控制字符，无 NFC/NFKC、不拒 U+202E（RTL override）/U+FF0F，`slice` 按 UTF-16 code unit 截断还可能切出半 surrogate。不构成路径穿越（`path.basename` 已去 `/`），属文件名欺骗。TC-09 的 5 个样本无 Unicode 项。

`○ L7-11 [Optional]【确认·低】health.lastError 未脱敏，development 默认关闭 5xx 脱敏`
- `app.js:92-99` `/api/health` 无鉴权且回 `chunkQueue.lastError` 原始 message（可能含 SQL/表名）；`app.js:161` `isSafeEnv = config.isDevOrTest()` 含 development → `:190` 5xx 回传 `error.message`。Dockerfile 已正确设 `NODE_ENV=production`+`AUTH_MODE=secure`，风险仅限误用 `.env.example` 的 development 值。

`○ L7-12 [Nit]【确认·配置触发】userId 含冒号破坏三处 `:` 拼接契约`

## 8. 误报澄清 / 需要降级的项

| 结论 | 澄清 |
|---|---|
| `paused` 即销毁 Worker 是「功能 Bug」 | **不是**。bridge 注释明确说明这是避免回池挂起闭包的有意决策；真正问题是 Worker 内 ~25 行挂起状态机与对应直测成了死路径（架构冗余），以及 terminate 打断未提交的 IDB 事务。 |
| `baseURL=""` 导致「token 外泄」 | **降级**。`allowedHosts=[]` 确实让 `isUrlAllowed` 恒 true，但此时所有 URL 都是同源相对路径，不会发往外域；真正的功能失效是 `baseURL="/api"` 时鉴权头全部漏发导致 401。 |
| `dedupeByContentKey` 丢弃 rebind 是线上 Bug | **降级**。生产链路用 `reconcileIncomingFiles`，该函数只在测试里被引用；是死代码 + 测试锁定错误行为，不是当前线上缺陷。 |
| `SIZE_LIMIT_KB` 可覆盖是「门禁已失效」 | **降级**。CI 未设置该变量，属「可绕过的设计口子」而非已失效；建议改为拒绝外部改写。 |
| `rowSelection` O(N²) | **降级**。主上传表格未启用 `rowSelection`，是未来启用时的潜在风险。 |
| `Title level=4 渲染 h1` | 确认是真缺陷（a11y 大纲），但无视觉表现，属 Required 而非 Critical。 |
